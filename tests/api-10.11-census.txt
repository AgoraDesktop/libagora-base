# The second denominator. `api-10.6-census.txt` measures what the tree answers against the reference `Foundation.h`
# names; this one measures the surface COCOA-10.11-SURFACE-PLAN.md commits to, and `FOUNDATION-10.11-PLAN.md` stages.
# They are different questions and both stay: the 10.6 pin catches a door that disappears from the older surface, and
# the §11.0 baseline in `Foundation.h` still governs what may be removed. Neither supersedes the other.
#
# THE REFERENCE IS macOS 10.11 AND THE SDK IS NOT IN THIS REPOSITORY. What is committed is the RECIPE
# (`api/10.11/README.md`) and the generated NAME MANIFEST (`api/10.11/foundation-manifest.txt`: 220 classes, 40
# protocols, 185 functions, 3,763 declared selectors, plus the two exemption facts below). No declaration, comment,
# annotation or line of Apple's expression is copied; names and relationships are the same kind of fact as a symbol
# table.
#
# **THE DENOMINATOR IS WHAT A macOS CALLER CAN REACH, AND THE MANIFEST SAYS SO.** Two facts are removed before
# anything is counted, and both are committed as lines in the manifest rather than as a list in the tool:
#
#   * `ios-class NSBundleResourceRequest` — `NS_CLASS_AVAILABLE(NA, 9_0)` in `NSBundle.h`. Declared by this SDK,
#     absent from macOS, and with it its 11 declarations. It is the only such class in these 156 headers.
#   * `unavailable-selector <class> <selector>` — nine doors Apple marks `NS_UNAVAILABLE`: `-init` on NSBundle,
#     NSCalendar, NSDistributedLock, NSLocale, NSScriptCommandDescription and NSSpecifierTest, `-initWithKind:options:`
#     on NSXMLDTD, and NSProxy's `-allowsWeakReference` / `-retainWeakReference`. A door a caller must not send is not
#     a gap; charging them made the first pass read two phantom selectors and one phantom class.
#
# THE MEASURED POSITION WHEN THIS FILE WAS LAST PINNED: 198 of 219 classes, 3,422 of 3,521 selectors, 31 of 40
# protocols, 182 of 182 functions, 0 declarations without bodies. **The whole remaining gap is 10.8–10.11** — 22
# classes, 9 protocols, 99 selectors, no C functions — which is the finding that turned the Cocoa plan's Foundation
# sizing from a debt into a delta.
#
# **THE ARITHMETIC, SO A READER CAN CHECK IT WITHOUT THE SDK.** 220 classes − 1 iOS-only = 219 offered; 198 present +
# 21 missing = 219. The 198 classes own 3,521 of the manifest's 3,763 selector facts — 3,422 present + 99 missing —
# and the 242 left over belong to the classes this tree has yet to write plus the exempt iOS-only one. The 99 is
# FOUNDATION-10.11-PLAN.md appendix C's tail: eleven `-initWithCoder:` doors that are ONE `NSCoding` conformance
# decision, plus 88 individual doors.
#
# **THREE INSTRUMENT FAULTS WERE FOUND BY POINTING THE LEDGER AT THESE HEADERS, AND THIS FILE IS THE FIRST PIN THAT
# DOES NOT CONTAIN THEM.** Each produced a plausible wrong answer, and each has a regression case in
# `../libagora-app/tools/api-ledger selftest`:
#
#   1. A PROPERTY'S TRAILING ANNOTATION WAS READ AS ITS NAME, OR MADE THE PROPERTY DISAPPEAR. `re.search(r'(\w+)\s*$')`
#      over `@property (readonly) ObjectType firstObject NS_AVAILABLE(10_6, 4_0);` matches nothing, because the
#      declaration ends in `)`, so 299 property accessors were silently absent from the manifest — and the census never
#      charged them. The seven properties that end in a bare macro (`NS_RETURNS_INNER_POINTER`) went the other way and
#      were recorded as a selector with that name. One regex, two failure directions, 306 doors mis-measured.
#   2. A STRING LITERAL WAS READ AS SYNTAX. `NS_DEPRECATED(10_7, 10_11, 5_0, 9_0, "Use [NSURLSession
#      dataTaskWithRequest:completionHandler:] …")` put the sentence's selector inside the declaration's own span, so
#      two NSURLConnection doors were charged as missing under concatenated names that exist nowhere.
#   3. AVAILABILITY WAS NOT A FACT. `NA` and `NS_UNAVAILABLE` could not be distinguished from absent, which is where
#      the phantom class and the two phantom selectors came from; the manifest now carries both.
#
# TWO DIRECTIONS, AS IN THE 10.6 CENSUS: a metric that moves fails with a diagnostic, a metric that appears fails, a
# metric that disappears fails, and the arithmetic is checked as well as the counts. The only way to change this pin is
# to edit it in the same commit that says which wave moved it. The gate is `tests/api_census.cmake`; the parser is
# `../libagora-app/tools/api-ledger`; the built library is an input, because a declaration is not a door.
#
# ERA: this file measures 10.11 because that is what COCOA-10.11-SURFACE-PLAN.md commits to. `Foundation.h` names 10.6
# as this library's reference and carries a 10.2 baseline (§11.0) for removals; the 10.6 census measures the whole
# 10.6 surface a caller can reach. Three denominators, three questions, none of them interchangeable.
#
# **A SURFACE IS NOT A BEHAVIOURAL CLAIM.** This file says every name a caller can reach has a body or a disposition;
# what the bodies DO is measured by callers, in the suites `FOUNDATION-10.11-PLAN.md` §7 schedules.
#
# **W3a: `NSURLSessionConfiguration` — the URLSession family's first class, its 47 doors all with bodies.** classes
# 198 -> 199 and selectors 3,422 -> 3,469; the class is NOT in `Foundation.h` yet, because W7 takes the family into
# the umbrella once all seven classes exist.
# **W3b: `NSURLSession`, `NSURLSessionTask` and `NSURLSessionDataTask`, plus the family's five delegate protocols.**
# classes 199 -> 202, protocols 31 -> 36, selectors 3,469 -> 3,504 (18 of the session's 31 doors and all 17 of the
# task's). `selectors-offered` moves UP by 48 and `selectors-missing` by 13, and that is not a regression: a class
# that did not exist offered nothing, and declaring the session exposes the 13 download/upload/stream factories W3c/W3d
# add — the census is now measuring them as missing rather than not counting them at all.
# **W3c: `NSURLSessionDownloadTask` and `NSURLSessionUploadTask`, plus the eleven factories.** classes 202 -> 204,
# the session's own doors 18 -> 29, and `selectors-missing` 112 -> 101: the download/upload half is answered, and only
# the two stream factories remain missing from this class. `selectors-offered` moves by one — the download task's own
# `cancelByProducingResumeData:`, which a class that did not exist could not offer.
# **W3d: `NSURLSessionStreamTask` and the thirteen task-scoped category doors.** classes 204 -> 205, selectors
# 3,516 -> 3,538, missing 101 -> 86; offered 3,617 -> 3,624 (the stream task's own seven doors). The task-scoped doors
# also move the four classes' `sel:` lines — NSURLCache 14 -> 17, NSURLCredentialStorage 9 -> 13, NSHTTPCookieStorage
# 10 -> 13, NSURLProtocol 14 -> 17 — and NSURLSession 29 -> 31 for the two stream factories.
# **W4a: the extension value and host, the item provider and the file-access intent.** classes 205 -> 209,
# protocols 36 -> 37, selectors 3,538 -> 3,562; offered 3,624 -> 3,648 and missing unchanged at 86 (every new class's
# SDK selectors arrived with it).
# **W4b: the notification family.** classes 209 -> 212, protocols 37 -> 38, selectors 3,562 -> 3,615; offered
# 3,648 -> 3,701 and missing unchanged at 86 (the three classes arrived with their own SDK selectors).
# **W5: the XPC family and the script tasks, all refusals.** classes 212 -> **219 of 219**, protocols 38 -> **40 of 40**,
# selectors 3,615 -> 3,658 of 3,744 (86 missing, all on classes W6 fills); offered 3,701 -> 3,744. Every class of the
# 10.11 Foundation now exists in the tree; what is left of the surface is method fill, not classes.
# **W6b: the `NSAppleEventDescriptor` type doors.** The eight 10.11 factories and accessors — double, date, file URL,
# the two application-name forms, the process identifier and `+currentProcessDescriptor` — plus `-isRecordDescriptor`
# and the send that refuses by name. Missing 86 -> 74; methods-declared 4,289 -> 4,301.
# **W6c: the ordered set's predicate and enumeration half.** NSOrderedSet 57 -> 64 (the four options forms of the test
# searches and the two locale descriptions), NSMutableOrderedSet 32 -> 33 (`-filterUsingPredicate:`); missing 74 -> 66.
# The predicates are declared in NSPredicate.h where Apple declares them; methods-declared 4,301 -> 4,309.
# **W6d: metadata, versions, and the coordinator's intent door.** NSMetadataQuery 28 -> 34 (the two 10.9 block walks,
# `searchItems` and `operationQueue` with their setters), NSMetadataItem 3 -> 4 (`-initWithURL:`), NSFileVersion
# 16 -> 22 (the two stored flags, the saving-computer name, and the replacement), NSFileCoordinator 14 -> 15 (the
# asynchronous intent door). Missing 66 -> 52; methods-declared 4,309 -> 4,323. The version replacement is the wave's
# acceptance: it runs inside an intent accessor, which is why W4 landed NSFileAccessIntent.
# **W6e: the operation family, progress publishing, and the JSON stream doors.** NSOperation 16 -> 21 (name,
# qualityOfService and their setters, isAsynchronous), NSOperationQueue 15 -> 19 (qualityOfService and its setter,
# underlyingQueue and its setter), NSProgress 31 -> 36 (publish/unpublish, the subscriber pair, isOld), and
# NSJSONSerialization 3 -> 5 (the two stream doors, whose heading said they needed a stream class the tree did not
# have). Missing 52 -> 36; methods-declared 4,323 -> 4,339.
# **W6f: the tail's singles.** NSLinguisticTagger 9 -> 13 (the 10.7 language door, the batch tags, the lattice and the
# edit notice), NSRegularExpression 12 -> 15 (the two escapers and one result's replacement), NSPointerArray 14 -> 18
# (the four 10.5 factories), NSUserActivity 29 -> 32 and NSDateComponents 39 -> 41 and NSProcessInfo 28 -> 29 (getters
# spelled with Apple's `is` prefix, which the ledger asks for), NSNetService 24 -> 26 and NSNetServiceBrowser 9 -> 11
# (`includesPeerToPeer`), NSXMLParser 18 -> 22 (the external-entity policy and allowed list). Missing 36 -> 11 — only
# the scripting family's `initWithCoder:` remains; methods-declared 4,339 -> 4,358.
# **W6g: the eleven NSCoding conformances, and the wave is complete.** Every scripting specifier, the two whose-tests,
# the command and its description archive their own state; NSDistantObject declares the conformance and BOTH coder
# doors refuse by name (a connection cannot be rebuilt from an archive). `selectors-missing` 11 -> **0 of 3,744**;
# methods-declared 4,358 -> 4,376; designated 130/148 -> 140/158 present. The number cluster's 18 designated marks are
# what remains, and they are W7's.
