# THE 10.6 API CENSUS — how much of the Mac OS X 10.6 Foundation this tree answers, pinned.
#

#
# The Foundation half of libagora-app's census, on the same terms and with the same instrument (`tools/api-ledger`,
# which lives in that component and is pointed at from here). It exists because "Foundation 10.6 parity" had never
# been a number: `Foundation.h` has named a 10.6 reference and this file for several slices, and this is that file.
# The AppKit tier showed why the number must be recomputable — three hand counts of its gap gave 4%, 44% and 54%,
# each measuring a different thing — and the same would have happened here.
#
# THE REFERENCE IS 10.6, AND THE SDK IS NOT IN THIS REPOSITORY. What is committed is the RECIPE
# (`api/10.6/README.md`) and the generated NAME MANIFEST (`api/10.6/foundation-manifest.txt`: 173 classes, 23
# protocols, 183 functions, 2,840 declared selectors). No declaration, comment, annotation or line of Apple's
# expression is copied; names and relationships are the same kind of fact as a symbol table.
#
# THE MEASURED POSITION WHEN THIS FILE WAS LAST PINNED — THE SURFACE IS COMPLETE: 173 of 173 classes, 2,840 of 2,840
# selectors, 23 of 23 protocols, 180 of 180 functions.
#
#   * F1 CLOSED THE 10.6 ROOT-CLASS AND VALUE DOORS. The root class answers the runtime hooks, the delayed and threaded
#     perform family, the OpenStep KVC spellings and the stored accessor, KVO's dependency rule in both spellings, the
#     comparison protocol and the error-recovery callback; the informal delegate protocols are declared and marked
#     FN_INFORMAL (56 rows, counted in `methods-informal`); and the 10.4- and 10.6-era accessor families are real.
#     `tests/object_surface.m` is the caller that measures the behaviour rather than the presence.
#   * F5 RESTORED NSCondition on the pthread body that had been re-homed as FNCondition, and F11 declares
#     NSSimpleCString (a real C-string-backed concrete string) and NSGarbageCollector (the documented no-collector
#     answers).
#   * F10 IS IMPLEMENTED AS A WORKING SCRIPTING MODEL: object specifiers and their eight element kinds, whose-tests and
#     logical tests, the nine standard commands, class and command descriptions and the suite registry, and the
#     NSObject scripting category. The AppleEvent DESCRIPTOR is a real data type (bytes, lists, keyword records and
#     coercion); execution — NSAppleScript and NSAppleEventManager — REFUSES BY NAME, because this system has no OSA
#     component and no AppleEvents transport. That is the plan's stated F10 disposition, not an omission.
#   * F3 IS IMPLEMENTED OVER A PROVIDER THIS LIBRARY OWNS: NSMetadataQuery walks its search scopes (the file system),
#     builds NSMetadataItems with the kMDItem attributes it can observe, applies the predicate, sorts, groups and
#     produces value-list tuples. The first gathering is synchronous; LIVE UPDATES are a run-loop poll of the same walk
#     (half a second, or -notificationBatchingInterval), diffed by path and announced with
#     NSMetadataQueryDidUpdateNotification. `-disableUpdates`/`-enableUpdates` start and stop that poll.
#   * F6 IS DECLARED AND REFUSED BY NAME: an NSNetService stores its domain, type, name, port and TXT record (the TXT
#     codec is a real wire format), but publishing, resolving and browsing report NSNetServicesInvalidError to the
#     delegate, because no DNS-SD responder exists on this system. The header names the requirement.
#   * `methods-declared-not-implemented` IS 0. The last three were NSAffineTransform's `-set`, `-concat` and
#     `-transformBezierPath:`, which THIS FRAMEWORK DECLARES AND APPKIT IMPLEMENTS (they act on a graphics context and
#     an NSBezierPath; Foundation must not import the drawing API). They are marked FN_COMPANION, counted in
#     `methods-external`, and implemented in libagora-app/NSAffineTransformAdditions.m — so the split is visible rather
#     than reading as an unfinished door, and no declaration in this tree is left without a body somewhere.
#   * FUNCTIONS ARE COMPLETE, and the two inline doors that looked missing are found where they are declared:
#     `NSMakeRange` and `NSMaxRange` live in `libagora-core/include/CFBridgingTypes.h` and the gate passes that
#     directory as `--include`. `NSCountFrames` ships with the stack walk NSThread and NSException share.
#
# **A COMPLETE SURFACE IS NOT A BEHAVIOURAL CLAIM.** This file says every name a caller can reach has a body; the two
# probes (`object_surface`, `scripting_surface`) and the rest of the suite are what say the bodies behave. The plan's
# M2 tier is the remaining work, and it is measured by callers, not by this census.
#
# THREE INSTRUMENT FAULTS WERE FOUND BY POINTING THIS LEDGER AT FOUNDATION, AND EACH PRODUCED A PLAUSIBLE WRONG
# ANSWER. They are recorded because they are the reason the numbers above are trusted:
#
#   1. LIGHTWEIGHT GENERICS DISABLED INHERITANCE. `@interface NSMutableArray<ObjectType> : NSArray<ObjectType>` put a
#      parameter clause before the colon, so the superclass was read as None and the class stopped inheriting NSArray's
#      BODIES — 8 implemented doors were counted as phantom. The superclass reader now skips the depth-counted clause.
#   2. C FUNCTIONS DECLARED INSIDE `@interface` WERE INVISIBLE. The scan blanked every `@interface … @end`, and this
#      library declares `NSStringFromClass`, `NSClassFromString`, the allocation family and the zone/page primitives
#      there. They were reported as symbols with no declaration — a fault the gate fails on. The blanking is gone; the
#      line anchor is what excludes methods, which begin with `-`, `+` or `@`.
#   3. TOKEN-PASTED MACROS HID 44 DOORS. `FN_NUMBER_GET(Int, int)` generates `-intValue` through `NAME##Value`, and
#      the accessor reader substituted the parameter for the whole name. Substitution is now per `##` piece, and the
#      shapes are read from the file while the call sites are read from the block, because the `#define` sits above
#      the `@implementation`.
#
# ERA: this file measures against 10.6 because that is the tree's own reference. `Foundation.h` also records a 10.2
# BASELINE used to decide removals (§11.0); that rule and this denominator are different questions. The 10.3–10.6
# additions that baseline had excluded are now ANSWERED — including NSCondition (10.5), which the baseline had cut and
# this file now counts as present — which is the difference between a door the baseline removed and a door nobody
# finished: the first is a decision, the second is a gap.
#
# TWO DIRECTIONS, AS IN THE APPKIT CENSUS: a metric that moves fails with a diagnostic, and the only way to change
# the pin is to edit this file in the same commit that says what landed. The gate is `tests/api_census.cmake`; the
# parser is `../libagora-app/tools/api-ledger`; the built library is an input, because a declaration is not a door.
#
